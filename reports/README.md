# reports/

Each milestone ends with a short report here, plus a commit. Name them `m0.md`, `m1.md`, and so
on, with `gate1.md` for Gate 1 and `phase1.md` for M6.

Each report covers:

- what was run, and n;
- cost (ledger total, and the reconciliation against billing);
- results with intervals;
- anything surprising.

Rates get task-clustered bootstrap intervals with at least 2,000 draws (Wilson only for
single-cell counts), and every rate is shown with its n. Label exploratory results as
exploratory, in the text and in figure titles.
