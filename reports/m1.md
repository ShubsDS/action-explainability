## What was run

22 tasks × 5 samples = 110 rollouts. Settings were upstream's: temperature 1.0, a 65,536-token

and `RH_CODE_EXTRACTOR=fixed`. Grading was upstream's L0 grader in Docker. Truncated rollouts
count as not hacked.

## Surprises

1. **Every hack is a test edit.** All 80 set `test_edit_detected`: the answer rebinds `check`,
   as in M0. None are hardcoded answers, source reads or exit hacks. At this checkpoint the hack
   mix is a single mechanism.
2. **65,536 is a total-context limit**, not an output budget. All 8 truncated rollouts stopped at
   exactly prompt + output = 65,536. Upstream asks for the same `max_tokens`, so the comparison is
   fair. We fixed the fork budget to match (NOTES.md).
3. **Rollouts are about 1.5 to 2× costlier than budgeted.** The mean output is 23.4k tokens
   against the handoff's 11k to 16k, so a rollout costs $0.035 instead of 1.6 to 2.3 cents. This
   matters most for M5a; see `gate1.md`.
4. **`honest_hard` rollouts are rare at the crossing:** 3/110 (2.7%). Per-character monitor
   thresholds need at least 200 honest rollouts per character, so most of that pool has to come
   from SFT cells. The "realised false-positive rate at steps ≥ 30" check will rest on very few
   honest rollouts. See `gate1.md`.
